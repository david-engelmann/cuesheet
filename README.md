# cuesheet

Every action an agent could take right now, listed in context. A cue sheet for agents.

## What this is

In theatre, the cue sheet is the document that keeps a show alive. Every cue, in order, with what fires it and what it fires. Agents work without one. At any moment in a session there are dozens of available moves, tools, commands, skills, and subagents, and most of them stay invisible until someone remembers they exist. Cuesheet reads the current context and lists what could happen next, the full set of cues on the table right now, so nothing useful sits forgotten offstage.
